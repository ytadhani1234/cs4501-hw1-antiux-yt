University Usability Engineering Assignment

ROLL NO. 21: SPACE MEIN DHOOM DHADAKA

Anti-UX Documentation

← Return to mission

SUPPORTED TASK

The user must restore the Power, Navigation, Communications, and Engine systems of Kris's damaged spacecraft and then launch the ship back to Earth.

The mission is deliberately difficult to use, but every required path works and the timer measures the full attempt.

INTENTIONAL USABILITY VIOLATIONS

1Attention 3.2 — Familiar Patterns & Prior ExperienceCounterintuitive colorsGlobalKanishkOS reverses familiar status conventions. Red represents active, successful, and operational states, while green represents shutdown, cancellation, and deactivation.

Only local subsystem status is shown, forcing users to remember which systems they already restored.
4Attention 3.1 — Stimulus Salience / Understanding User GoalsWrong information demands attentionGlobalIrrelevant KanishkOS Premium advertisements use bright colors, animation, and large typography while important task instructions are visually weaker.
5Reading 5.1 — Avoid Text on Noisy BackgroundsReading is unnecessarily difficultNavigation, Communications, EngineSome task-relevant text appears over stars, nebulae, signal grids, and technical schematics instead of clean plain backgrounds.
6Thinking 5.2 — Let Users Use Perception Instead of CalculationsUser must perform arithmeticPowerThe interface gives total reactor capacity and three existing allocations but refuses to calculate the remaining Propulsion allocation. The user must determine that the answer is 35.

CORRECT TASK PATH

  1. POWER: Total 100 units − 31 Life Support − 18 Navigation − 16 Communications = 35 Propulsion Reserve. Enter 35 and resolve the configuration.
  2. NAVIGATION: Choose Milky Way → Orion Spur → Sol → Terrestrial Worlds → Earth, then apply the vector.
  3. COMMUNICATIONS: Remember K21-4187-X, proceed to the transmitter, enter K21-4187-X, and establish the relay. Reacquire Relay lets you return to the code if needed.
  4. ENGINE: Set Operating Mode to SAFE-BURN, set Thermal Bypass to OFF, then press PRIME → ARM → EXECUTE.
  5. Open LAUNCH CONTROL, then press LAUNCH TO EARTH.
